# 抖音敏感词检测分类详解

本文件说明抖音平台 10 大审核维度与各维度词库来源，Skill 在调用 `scripts/sensitive_check.py` 时以此为判定依据。

## 维度 7（绝对化用语）的豁免规则

绝对化用语是最容易被误判的维度。**两类用法可以保留**：

### ✅ 可以保留（正常列举）
- 序数词列举：**第一、第二、第三**（不是广告宣称，是正常列表）
- 口语强调词但有具体语境：**最要紧**（= "特别要紧"）、**最好**（= "推荐"）

### ❌ 必须修改（广告宣称）
- **最** / **顶级** / **唯一** / **国家级** / **100%** / **百分百**（出现在商品/服务宣传）
- **最强** / **极致** / **完美** / **全面** / **首屈一指**（无具体语境支撑）

### 修改替换表

| 命中词 | 替换为 |
|--------|--------|
| 最 | 特别 / 非常 |
| 第一 | 推荐 / 首选 |
| 顶级 | 优质 / 出色 |
| 唯一 | 仅此一款 / 限定 |
| 国家级 | 行业级 / 高水平 |
| 100% / 百分百 | 大幅 / 充分 |
| 最强 | 出色 / 强劲 |
| 完美 | 出色 / 完整 |
| 全面 | 多角度 / 全方位 |

## 维度 8（诱导互动）的判定细节

诱导互动是抖音强打击项，但**正常的 CTA 描述可以保留**：

### ❌ 命中（强诱导）
- "点赞关注我！""转发给朋友！""加微信领取…"
- "扫码加群""点击链接""私信我"

### ✅ 可以保留（功能性描述）
- "喜欢的朋友可以收藏"
- "评论区聊聊你的经验"

## 词库来源

`scripts/sensitive_check.py` 中的 BANK 词典收录了 10 维度常见词。**词库需定期更新**，建议每月根据平台最新公示补充一次。

## 检测记录规范

每次命中后，仿写稿文末必须附检测记录表：

```
===== 敏感词检测记录 =====
| 命中词 | 维度 | 上下文 | 处理结果 |
|--------|------|--------|----------|
| 包治   | 医疗健康夸大 | … | 已改为 "有效调理" |
| 100%   | 绝对化用语   | … | 已改为 "充分" |
======================
```

如全部通过，附：
```
===== 敏感词检测记录 =====
本次扫描未命中任何敏感词，通过抖音平台审核要求。
======================
```
